Pergunta 1:Explique a Diferença entre Branch, Merge e Pull Request

Uma branch é uma linha paralela de desenvolvimento que permite trabalhar em novas funcionalidades ou correções isoladamente, sem afetar o código principal; o merge é o processo de juntar as alterações
feitas em uma branch de volta à branch principal, integrando as mudanças; já o pull request é uma solicitação feita em plataformas como GitHub para que outros desenvolvedores revisem, discutam
e aprovem essas mudanças antes que o merge seja realizado, garantindo qualidade e colaboração no código.
