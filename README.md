# Atividade-BranchNova
Respondendo perguntas
A criação de branches em um projeto é fundamental para organizar e isolar o desenvolvimento de novas funcionalidades, correções de bugs ou experimentos sem impactar o código estável da branch principal. Isso permite que várias pessoas trabalhem simultaneamente em diferentes partes do projeto, reduzindo conflitos e facilitando o controle das mudanças. Entre as boas práticas ao criar uma branch estão: dar nomes claros e descritivos que indiquem o propósito da branch (exemplo: feature/login, bugfix/corrigir-login), criar a branch a partir da versão mais atualizada da branch principal, manter as branches pequenas e focadas em uma tarefa específica, e atualizar sua branch regularmente com as mudanças da principal para evitar grandes conflitos na hora do merge.
